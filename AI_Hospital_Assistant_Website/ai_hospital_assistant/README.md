# CareAI — AI Hospital Assistant

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge, or use VS Code Live Server.
3. Everything in this demo runs client-side.

## Included
- Responsive hospital admin dashboard
- Appointments with create/search/filter
- Patient records
- Doctor availability
- Working AI-style assistant with sample hospital knowledge
- Settings/toasts/modal interactions
- No backend or API key required

For a production project, connect the forms and AI assistant to a secure backend/database and use an approved medical/clinical AI service with appropriate safety controls.
